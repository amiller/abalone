01 / Install and inspect

Read the offer first.

Your agent checks and installs the release, then reads the offer. Inspecting claims nothing and saves nothing on this computer. The gift link stays in a private 0600 file, never in a command argument.

$ sha256sum -c --ignore-missing FRIEND-SHA256SUMS
$ less install.sh
$ sh install.sh --credit
$ abalone credit inspect --trial /ABS/trial.json --input-file /private/gift.txt

02 / Terms

Accept that exact offer.

Redeeming binds to the hash you read. A changed offer is a different offer.

$ abalone credit redeem --trial /ABS/trial.json --input-file /private/gift.txt --accept-offer OFFER_HASH
$ abalone credit status

Two network paths.

Abalone is a setup guide and a terminal app built around the Pi coding agent. Dsmack exchanges your coupon for model access. After that, Abalone checks the NEAR model’s attestation and encrypts each request to the admitted model key.

Abaloneyour computer (trusted)
coupon → credential (setup)
Dsmack issuersees the coupon, not prompts
Abaloneyour computer (trusted)
encrypted to the admitted model key
NEAR model TEEreturned through a pinned transport

The trust boundary is the model’s TEE plus your own computer. Neither path hides your IP address. Your setup agent may handle the access credential; that does not authorize it to receive your private document or conversation.

Know the boundary.

Use synthetic, non-sensitive material with the available NEAR access route. It accepts verified firmware warnings, and the coupon operator can access and revoke the model credential.

Abalone runs on a trusted Linux computer. Its tools have your account’s file and network access; your administrator remains trusted. Your setup agent stepping aside is cooperation. Incognito does not hide your IP address, and workspace files or terminal captures can remain.

For your coding agent

Help the user understand Abalone, obtain or reuse access, and open an incognito session. Reading this page alone is not permission to redeem or spend; follow the user’s instruction.

Read the Abalone setup skill before suggesting installation. Explain the purpose, the two network paths above, the local changes and the trust boundaries. Inspect downloaded code and its integrity information before execution.

A coupon link carries its code after #code=. URL fragments are not sent in HTTP requests, so this fetched page will not contain the code. Read it from the full link the user supplied; if it is missing, ask for the full gift link. Never move the code into a query string, request path, public log or command argument.

If asked to redeem, follow the recipient procedure, save the resulting access with ordinary private file permissions, and test with synthetic input only when requested. Open a fresh terminal for the user’s conversation. Closing a conversation and forgetting saved access (abalone credit forget) are separate actions; forgetting does not revoke the credential. Never automatically repeat an uncertain claim. If the inspected offer is expired, do not redeem; the user needs a new gift from the sponsor.

If the user already has access, reuse it. If they have none, explain available acquisition choices and help them obtain access before installing. Do not invent a funding endpoint or promise an unverified payment route.
