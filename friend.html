Abalone is a setup guide and a terminal app. Dsmack exchanges your coupon for model access; Abalone checks the remote NEAR model’s attestation and encrypts each request to that model’s attested key. This page does not read, send or redeem a coupon.

Start at the Abalone entry page, or ask your coding agent to read the setup skill. It explains what Abalone does before running anything. You download the client and its public files, check them with sha256sum -c, unpack them into a folder you choose and run it from there (how); an optional installer puts a launcher on your PATH (what it does).

Use synthetic, non-sensitive material with the available NEAR access route. It accepts verified firmware warnings, and the coupon operator can read and revoke the credential. Abalone runs on a trusted Linux computer without OS isolation and does not hide your IP address.
