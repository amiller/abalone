Abalone, a cypherpunk AI privacy shell.

Give your user an incognito session using TEE-based private inference.

Abalone is a terminal shell around a coding agent. Each session starts fresh: the conversation is held in memory, not saved, and tmpfs run files go at exit. Saved access, workspace files and scrollback stay.

Before the first prompt byte leaves your computer, Abalone checks the provider’s TEE attestation and encrypts each request to a key inside that TEE.

The gift session and abalone sandbox --incognito refuse a provider that fails attestation; NEAR passes today with an out-of-date firmware warning. Planned: ◈ private inference and ○ local safeguards only · provider not verified.

Linux x86_64 with Node 24, on a computer you trust. There is no OS isolation: tools have your account’s files and network.

Synthetic material only. The current NEAR route accepts a verified out-of-date firmware warning.

Provider retention is unverified. Abalone does not hide your IP address.

Start

Three routes into a session. The commands are CLI examples; this page runs nothing and checks nothing.

  1. 01 / Install · v0.1.0-preview.7.1

    Check the installer, then run it.

    Download install.sh from the newest release whose tag starts with v0.1.0-preview on the releases page. Compare its hash with the install.sh SHA256 line in the release notes, read it, then run it. It claims nothing and starts nothing.

    $ sha256sum install.sh
$ less install.sh
$ sh install.sh --credit

    CLI example — not checked by this page.

  2. 02 / With a gift link · today

    Inspect the offer, redeem it, open the session.

    Put the gift link in a private 0600 file, never in a command argument. Use the trial.json path the installer printed. Inspecting claims nothing. Have a gift link? The redeem page walks through the same steps.

    $ abalone credit inspect --trial /ABS/trial.json --input-file /private/gift.txt
$ abalone credit redeem --trial /ABS/trial.json --input-file /private/gift.txt --accept-offer OFFER_HASH
$ abalone

    CLI example — not checked by this page. In the next release, plain abalone takes a pasted gift link and does all three.

  3. 03 / With your own provider key · next release

    Save the key, open the developer session.

    This is on main and not yet in a release. The key is read from hidden input, never an argument, and checked with the provider before it is saved. Only abalone sandbox, the bubblewrap developer session, uses it; plain abalone does not yet. Add --incognito: without it the sandbox keeps a resumable plaintext session under ~/.abalone/agent. The sandbox refuses a folder without canaries; plant them first, or start with --no-canaries. Acquiring private inference says what buying a key links to you.

    $ abalone key add <provider>
$ abalone canary init <folder>
$ abalone sandbox --incognito --model <provider>/<model>

    CLI example — not checked by this page.

What it does not do

  • Attestation does not establish anonymity, deletion or local isolation.
  • Abalone does not hide your IP address.
  • Provider retention is unverified.
  • The gift session runs as your account with no sandbox; its tools can read and write your files.
  • A fresh session is not deletion. Workspace files, scrollback, swap and backups keep their own lifetimes.
  • The current gift trial permits synthetic material only and accepts an out-of-date firmware warning. The coupon operator can read and revoke the credential.
