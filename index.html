Abalone, a cypherpunk AI privacy shell.

Give your user an incognito session using TEE-based private inference.

Abalone is a terminal shell around a coding agent. Each session starts fresh: the conversation is held in memory, not saved, and tmpfs run files go at exit. Saved access, workspace files and scrollback stay.

Before the first prompt byte leaves your computer, Abalone checks the provider’s TEE attestation and encrypts each request to a key inside that TEE.

The gift session and abalone sandbox --incognito refuse a provider that fails attestation; As of 2026-10-13, NEAR verifies with an out-of-date firmware warning: its TDX platforms are one Intel TCB recovery behind (SVN 3 of 4), and this trial accepts that with a visible warning. Planned: ◈ private inference and ○ local safeguards only · provider not verified.

Start

An Abalone session needs a model to talk to. Pick where yours comes from. Commands are CLI examples; this page runs nothing and checks nothing.

  1. 01 / Your own provider key, or a local model

    Build from source, open the developer session.

    Clone the repository and follow CONTRIBUTING to build it (Linux x86_64, Node 24). The session is abalone sandbox --incognito: a bubblewrap sandbox, egress only to admitted hosts, canaries in your folder. abalone key add saves a provider key from hidden input; it is on main and ships in the next release.

    $ abalone key add <provider>
$ abalone canary init <folder>
$ abalone sandbox --incognito --model <provider>/<model>

    CLI example — not checked by this page.

  2. 02 / A gift from someone running Dsmack

    Open the link they sent you.

    A gift link opens the redeem page, which installs the released client and turns the gift into a saved credit for an incognito session. Everything about that route lives there.

  3. 03 / Zcash · planned

    Pay for private inference without an account.

    Swap Zcash for a slice of model access and open the session. Not built yet; the acquiring guide tracks it.

What it does not do

  • Attestation does not establish anonymity, deletion or local isolation.
  • Provider retention is unverified, and your IP address is not hidden.
  • The current gift trial is for synthetic material and accepts an out-of-date firmware warning.
