# Dedicated SDK child host: offline prototype

This new slice does not change the inference broker or make production billing available. It wraps the separately reviewed `sdk-adapter-child-core.mjs` in a one-request process running as financial UID 972. Tests here use a synthetic SDK and synthetic lease, not a real vault lease or accepted production tariff. The earlier actual SDK and HPKE fixture proofs remain separate.

## Trusted constructor and ownership

`createSDKChildHost` accepts only a trusted caller's configuration: `trustedRoot`, absolute `nodePath`, `childEntry`, `wrapperPath`, `sdkLoaderPath`, `verifyRuntime`, `lease`, `chargePolicy`, `admissionPolicy`, `permitRawPost`, and bounded `deadlineMs`. These must never become worker-request fields. It requires UID 972; code paths and their ancestors below filesystem root must be real, root-owned, and not group/world writable. `verifyRuntime(signal)` must verify the pinned complete SDK dependency closure, interpreter, and adapter code, not just the loader. There is no default verifier, admission policy, charge policy, credential location, environment fallback, or HOME fallback.

The caller explicitly supplies `lease = { fd, assertCurrent(signal), release() }`. The descriptor must be an already-open read-only regular financial-UID file, private mode, at most 16 KiB. The JSON record contains only authorization, userCacheSecret, recordId, and generation. The host does not parse or put these fields in control messages. The child gets that descriptor as FD 4, reads it by explicit offset, and passes authorization/cache secret directly into the SDK core. Secrets are not passed through argv or environment. JavaScript strings and SDK copies are not claimed to be securely zeroized; process exit bounds their lifetime.

The real lease implementation is still required: validate expected vault UUID, current mount identity, record identity/generation and financial ownership; pin the open descriptor until the child is reaped. Ordinary lock must refuse while the lease is held. `assertCurrent` must fail after lock, replacement or revocation. Neither this file nor its tests proves those actual vault properties. The constructor bounds startup callbacks and passes an abort signal; on constructor refusal before returning a host, the caller still owns and must release the lease. Once returned, host close releases it only after child exit. Lease release is a trusted cleanup operation; a stuck release does not produce a false successful-close claim.

## Private IPC and request lifecycle

The only channel is inherited duplex FD 3. Frames have a four-byte big-endian length, maximum 64 KiB; unknown fields, oversized frames, duplicate or out-of-order incoming call IDs, unsolicited replies and more than two in-flight calls are refused. Request and admission documents move in acknowledged chunks of at most 32 KiB, with 4 MiB totals. Stream output is pull-driven, at most 32 KiB per acknowledgement and 8 MiB total. There is no public listening socket.

`prepare({logicalId, body, signal})` sends one body, invokes the root admission callback with the core's verified binding, and returns a host-local opaque handle plus request/document digests. `post({handle, signal})` accepts only that exact handle; it cannot accept a replacement body. It returns `{stream}`. Successful EOF is delivered only after child exit and lease release have completed. If cleanup fails, the stream errors instead of reporting successful EOF. Explicit callers may still await the idempotent `close()`. All failures close and reap the process; handles cannot be retried or reused.

Immediately before the core's one raw POST, the child asks the host for a private permit. The host checks the logical ID and both admitted digests, verifies the still-current lease and descriptor inode/device, and calls `permitRawPost(details, signal)`. Only one permit request is accepted. The core then checks abort state and the same frozen charge policy immediately before native fetch. The future broker callback must durably journal/reserve the exact request before granting permission and retain an uncertain outcome after ambiguous network failure. This slice does not implement that journal, refunds, account balances or a production billing contract. Missing or unqualified contracts must deny POST.

## Termination and proof scope

A fixed Python wrapper sets Linux `PR_SET_PDEATHSIG=SIGKILL`, checks the original parent PID, and execs the fixed Node/child paths with a minimal environment. Explicit abort, channel failure and request deadline terminate the child: SIGTERM, 100 ms grace, then SIGKILL if necessary, followed by wait for exit before lease release. The financial FD and control FD are the only special inherited descriptors. Child stdout/stderr are discarded, bounded to 64 KiB, never logged.

The isolated test runner stages root-owned source on temporary `/run`, maps UID 972, and disables external IPv4/IPv6 networking. Twenty-three host cases cover streaming, admission denial, private permit binding, revoked lease, TERM-resistant abort/reap, actual parent death, missing authority, startup callback timeout, writable-FD refusal, and fourteen malformed peer payload/reply cases. Strict operation schemas require ordinary objects, all required fields and no extra fields; stream replies are exactly `{done:true}` or `{chunk:string}`, never both. Six direct schema cases plus seven wire cases cover malformed, replayed and excessive frames, timeout and fragmented valid input. The namespace supervisor reaps the orphan in the parent-death test. No real credential, provider call or guest mutation is involved.

Before durable integration: qualify the real vault lease, root-owned deployed interpreter/SDK closure, the broker's actual journal permit, and live charge-contract semantics under separately approved deployment. Do not treat synthetic fixture admission as production approval.
