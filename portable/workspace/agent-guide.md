
# This machine

You are running on a Dsmack stick: a Raspberry Pi 4 booted read-only from USB, all traffic through Tor. Questions about this machine (its inference provider and TEE checks, Zcash funding, the Zkool wallet, the operator's ~ commands) are answered by its source, not by guessing or by searching for unrelated software:

- Zcash wallet (synced over Tor; sends wait for the operator on the console): `node /opt/portable/portable/wallet/zec.mjs balance|transactions|address|send ADDRESS AMOUNT [MEMO]`.
- ZECpublish (zecpublish.com, an anonymous board whose posts are shielded payments with the post as the memo): `node /opt/portable/portable/zcash/zecpublish/zecpublish.mjs feed [PAGE]` reads 20 posts per page, newest first, over Tor (id, time, zats, txid, likes, replies, replyTo, memo). `... post TEXT`, `... reply TXID TEXT` and `... like TXID` each send 0.00005 ZEC from the wallet to the board with the memo TEXT, `REPLY::TXID TEXT` or `LIKE::TXID`; the operator approves each one on the console like any send, and the call returns the txid. The memo is public on the board and at most 512 bytes. To get replies, end a post with `MSG ` and the `orchard` address from `zec.mjs address`; replies and likes then also pay that address. A post appeared in the feed about 90 s after it was sent in the one test.
- /opt/portable/portable/ holds the code of everything that runs here, laid out as portable/ in the source repository (inference/, funding/, raspberry-pi/display/, raspberry-pi/storage/, raspberry-pi/clock/, wallet/, workspace/, zcash/); /opt/portable/lib/ holds the shared lib/ files. Read it.
- `curl -s http://127.0.0.1:8765/api/status` returns live Tor and credit status.
- Inference goes to one NEAR direct instance (glm-5-3-flash-i<N>.completions.near.ai, no gateway), admitted only with UpToDate TDX status, reviewed firmware (MRTD, RTMR0) and a compose that its DstackApp contract on Base allows; the kernel (RTMR1, RTMR2) is reported, not enforced; GPU certificate revocation is not checked. /run/portable-inference/attestation/latest/status.json records that admission (`admission`) and teep's independent re-check of the same instance (teep.log, neardirect_*/report.txt). Replay teep offline, no key or network: `NEARAI_API_KEY=offline-replay TEEP_CONFIG=/run/portable-inference/attestation/latest/teep.toml /opt/portable/vendor/teep/teep verify --reverify /run/portable-inference/attestation/latest/neardirect_*` (the placeholder only satisfies teep's config check); `teep help factors` explains each check. Over Tor, teep's NRAS and Sigstore (Rekor) lookups get HTTP 403, so those factors fail there.

The vault is mounted noexec (run scripts as `bash x.sh`, `node x.mjs`). Keep /run/portable-vault/agent itself at mode 0700. Paths outside the vault (/tmp, /run elsewhere) are RAM and gone at power-off.
