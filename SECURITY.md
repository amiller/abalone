# Reporting a security issue

Andrew Miller maintains Abalone at [amiller/abalone](https://github.com/amiller/abalone).
For a security report, request a private reporting channel through
[the maintainer's GitHub profile](https://github.com/amiller) or open an
[issue](https://github.com/amiller/abalone/issues) containing only a request for
private contact. Do not post exploit details, credentials, gift codes, private
prompts or session traces in public issues.

Include the affected revision, supported platform, a minimal reproduction using
synthetic data, the observed effect and your proposed disclosure timeline.
This development trial has no promised response time or supported historical
release branches. Incognito encrypts session traces and isolates Pi; it does
not provide VPN anonymity or protect against a privileged host operator.
