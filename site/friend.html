Start with the skill

Ask your setup agent to use the Abalone incognito skill. It checks support and prepares the reviewed reference helper when needed, then hands the interactive terminal to you. Do not send it your coupon, passphrase or private prompts.

The helper distribution includes a patched Pi agent, Abalone launcher, extensions, verification and credential broker. The first release runs without OS isolation on your trusted owned host; bubblewrap is a later milestone. Installing a skill alone does not install this runtime or add verified support for stock Pi or Hermes. The setup agent must stop observing/recording before your private input; stepping aside is cooperation, not protection from a same-user agent or administrator.

The installer and its checksums are the skill's setup mechanism. If you prefer the manual entry, inspect the installer, verify its checksum, then run:

Your passphrase protects that local trace, not the coupon. Keep it to open the trace later. Workspace files you create can remain after close.
